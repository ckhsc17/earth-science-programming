步驟 4: 資料結構對應
-------------------

COMCOT 使用:
```fortran
type grid_type
    real, allocatable :: z(:,:)  ! 地形
    real, allocatable :: h(:,:)  ! 水深
    real, allocatable :: m(:,:)  ! x方向動量 (hu)
    real, allocatable :: n(:,:)  ! y方向動量 (hv)
end type
```

我們的結構:
```fortran
type swe_grid_type
    real(8), allocatable :: bath(:,:)  ! 地形
    real(8), allocatable :: eta(:,:)   ! 水位
    real(8), allocatable :: h(:,:)     ! 總水深
    real(8), allocatable :: u(:,:)     ! x方向速度
    real(8), allocatable :: v(:,:)     ! y方向速度
end type
```

對應關係:
- COMCOT z  ↔ 我們的 bath
- COMCOT h  ↔ 我們的 h
- COMCOT m  ↔ 我們的 h*u
- COMCOT n  ↔ 我們的 h*v

步驟 6: 更新 Makefile
--------------------

```makefile
# 加入 COMCOT 源碼
COMCOT_DIR = comcot_source
COMCOT_OBJS = $(COMCOT_DIR)/mass.o $(COMCOT_DIR)/moment.o $(COMCOT_DIR)/boundaries.o

# 編譯 COMCOT 模組
$(COMCOT_DIR)/%.o: $(COMCOT_DIR)/%.f90
	$(FC) $(FFLAGS) -c $< -o $@
```
